# Portfolio images

Drop real photos here with these filenames (referenced by the TODO comments in
each `_portfolio/*.md` file) and the placeholder images will be replaced
automatically:

| File | Project | Suggested size |
|---|---|---|
| `kanaloa-usv.jpg` | Autonomous Surface Vessel — Team Kanaloa | 1200×800, landscape |
| `climbing-robot.jpg` | Magnetic-Adhesion Climbing Robot — RIP Lab | 1200×800, landscape |
| `soft-fin.jpg` | Bio-Inspired Soft Robotic Fin — SAIL Lab | 1200×800, landscape |
| `asml-arm.jpg` | Reticle-Handling Robot Arm Controls — ASML | 1200×800, landscape |

To use one:
1. Add the image file to this folder.
2. Open the matching file in `_portfolio/` and replace every occurrence of
   `/images/500x300.png` with `/images/portfolio/<filename>` (there are two:
   one in the front-matter `excerpt`, one in the `<img>` tag in the body).
3. Delete the `<!-- TODO(Thomas): ... -->` comment block once done.

This file is just a note for you — delete it any time.
