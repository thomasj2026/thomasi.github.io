**Role:** Mobile Robotics Research Assistant · RIP Lab &nbsp;|&nbsp; **When:** May 2024 – July 2026

Helped build a 50-lb robot that climbs vertical steel surfaces using magnetic adhesion, from the magnet geometry through the sensor-fusion software that keeps it stable.

* Optimized magnetic-adhesion geometry in MATLAB and COMSOL FEA before fabrication to achieve stable vertical-surface operation
* Rapid-prototyped sensor housings and caster wheels in Onshape, produced in-house via FDM and resin 3D printing
* Built a C++ ROS 2 pipeline that fuses dual 9-DOF IMU streams through an Extended Kalman Filter, visualized live in RViz2
* Built a Python tool that monitors battery-enclosure temperature within 5% of a reference sensor across a full runtime cycle

**Tech:** COMSOL FEA · MATLAB · ROS2 · EKF · Onshape · Python
